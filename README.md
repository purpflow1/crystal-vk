# crystal-vk
**crystal-vk**  is a wrapper for Vulkan.

## Features
- [x] Linux, MacOS, Windows support
- [x] Safe lifetimes
- [x] Compute pipeline

---

## Running examples
To run debug scene from included example in
[github](https://github.com/purpflow1/crystal-vk) use:
```bash
cargo run --example general
```
